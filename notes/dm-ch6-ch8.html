DM05 (CH6)

01

Frequent Pattern

中文白話解釋

在 Data set 中頻繁出現的一組模式

02

Frequent Itemsets

中文白話解釋

偏向是「物品」的集合

03

Support

中文白話解釋

用來找到 Association Rule 的判斷值，例如：總交易筆數同時包含 A 和 B 兩個項目的比例

04

Confidence

中文白話解釋

在一個項目出現的情況中，另外一個項目出現的機率

05

Association Rules

中文白話解釋

商品間的條件推理關係。例如：當買一個物品時，就會買另外一個商品

06

Apriori Property

中文白話解釋

一個集合是 Frequent，它的所有子集合都會是 Frequent

DM06 (CH8)

01

Supervised Learning (Classification)

監督式學習
中文白話解釋

訓練資料皆帶有標籤，指出其所屬的類別。新資料集會根據 training set 進行分類。

02

Unsupervised Learning (Clustering)

非監督式學習
中文白話解釋

訓練資料類別標籤皆是未知。給定一組測量值或觀察值，目標是找出資料中是否存在不同的類別或群集。

03

Semi-supervised Learning

半監督式學習
中文白話解釋

利用有標籤與未標記的資料來建立分類器

04

Evaluating Classification Methods

評價一個分類模型的面向
  • Accuracy 準確度分類／預測的準確度
  • Speed 速度訓練需要的時間、分類的效率
  • Robustness 韌性處理雜訊和缺值的能力
  • Scalability 可擴充性演算法一次可以處理多少分析，處理的資料量越多，Scalability 越高
  • Interpretability 可解釋性

沒有符合的名詞，請試試其他關鍵字。

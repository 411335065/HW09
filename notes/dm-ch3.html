DM03 (CH3) 問答

01

Major Tasks in Data Preprocessing

  • Data cleaningFill in missing values, smooth noisy data, identify or remove outliers, and resolve inconsistencies.
  • Data integrationIntegration of multiple databases, data cubes, or files.
  • Data transformationNormalization and aggregation.
  • Data reductionObtains reduced representation in volume but produces the same or similar analytical results.
  • Data discretizationPart of data reduction but with particular importance, especially for numerical data.
02

Data Cleaning Tasks

資料清理任務
  • Fill in missing values填補缺失值
  • Identify outliers and smooth out noisy data識別異常值並平滑化雜訊資料
  • Correct inconsistent data修正不一致的資料
  • Resolve redundancy caused by data integration解決因資料整合所造成的冗餘問題
03

Missing Values 的解決方法

  • Ignore the tuple 忽略該筆資料通常用於分類任務中缺失類別標籤（Class label）時；但若各屬性的缺失比例差異極大，此方法效果較差
  • Fill in the missing value manually 人工填補過程繁瑣且通常不可行
  • Fill in it automatically 自動填補最有可能的方式：基於推理的模型（如貝氏公式或決策樹）進行預測填補
04

Noise 的處理方法

  • Binningfirst sort data and partition into (equal-frequency) bins, then one can smooth by bin means, smooth by bin median, smooth by bin boundaries, etc先將資料排序並分割為等頻率的 Bins，再透過 Bin means（箱平均值）、Bin median（箱中位數）或 Bin boundaries（箱邊界值）進行平滑化
  • Regressionsmooth by fitting the data into regression functions將資料擬合至迴歸函數中以進行平滑化
  • Clusteringdetect and remove outliers偵測並移除異常值
  • Combined computer and human inspectiondetect suspicious values and check by human (e.g., deal with possible outliers)由電腦偵測可疑數值，再由人工進行檢查與處理
05

Haar Wavelet Transform

首先鄰近的值兩兩相加，再相減，最後全部除以根號 2，便獲得一個資料表，與原始資料有相同的趨勢，適用於圖像。

06

Principal Component Analysis

假設每筆都有兩個屬性，試著找出一個新的座標體系（讓其中一個屬性值相同）。能夠解釋當中若干的座標軸上，轉換後只剩下一個屬性的差異，就能找出分佈的差異。

重點 但是降維後的屬性已經不是原來的屬性了！！

07

Heuristic Methods

啟發式方法
  • Step-wise forward selection從很少的特徵開始，一個一個加進來
  • Step-wise backward elimination從全部特徵開始，一個一個刪掉
  • Combining forward selection and backward elimination加、刪兩種方式交替使用
  • Decision-tree induction透過建立決策樹來找出重要特徵與分類規則
08

Normalization

正規化
  • min-max normalization 最小-最大正規化把資料縮放到指定範圍，最常見是 0～1
  • z-score normalization看一筆資料離平均值有幾個標準差
  • normalization by decimal scaling透過移動小數點來縮放資料

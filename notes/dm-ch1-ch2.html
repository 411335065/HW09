DM01 (CH1)

01

Big Data

English Definition

an all-encompassing term for any collection of data sets so large and complex that it becomes difficult to process using traditional data processing applications

中文白話解釋

指資料量極其龐大且複雜，以至於難以使用傳統資料處理的資料集集合

02

Data Mining / KDD

English Definition

The process of discovering interesting knowledge from large amounts of data stored in databases, data warehouses, or other information repositories

中文白話解釋

從儲存在資料庫、資料倉儲或其他資訊儲存庫中的大量資料中，發現有用且有趣知識的過程

03

Data Selection

資料選擇
中文白話解釋

原始資料庫或資料集中，根據分析目標篩選出與任務相關的子集

04

Data Transformation

資料轉換
中文白話解釋

將選定的資料透過維度縮減、特徵提取或格式整理，轉化為適合進行資料探勘演算法處理的形式

05

Pattern Evaluation

模式評估
中文白話解釋

利用特定的評估指標與標準，從探勘出來的各種模式中識別並篩選出真正有趣且實用的知識

06

Knowledge Presentation

知識呈現
中文白話解釋

運用圖表或視覺化等技術，將最終挖掘出來的知識以易於理解的方式展現給使用者

07

Objective

客觀標準
English Definition

based on statistics and structures of patterns

中文白話解釋

基於模式的統計數據與結構

例supportconfidence

08

Subjective

主觀標準
English Definition

based on user’s belief in the data

中文白話解釋

基於使用者對資料的信念與認知

例unexpectedness 意料之外性novelty 新穎性actionability 實用性

DM02 (CH2)

01

Data Object

資料物件
English Definition

A data object represents an entity. Data sets are made up of data objects

中文白話解釋

資料物件代表一個實體，而資料集由資料物件組成

02

Attribute

屬性
English Definition

a data field, representing a characteristic or feature of a data object

中文白話解釋

代表資料物件的特徵或特色

03

Discrete Attribute

離散屬性
English Definition

Has only a finite or countably infinite set of values

中文白話解釋

只有有限或可數無限的值集合。二元屬性是離散屬性的特例

例郵遞區號職業

04

Continuous Attribute

連續屬性
English Definition

Has real numbers as attribute values. Continuous attributes are typically represented as floating-point variables

中文白話解釋

屬性值為實數，通常以浮點變數表示

例0.31325.341

05

Redundant Attribute

冗餘屬性
中文白話解釋

重複、多餘或可被其他屬性替代／推導出的特徵或欄位

06

Data Visualization

資料視覺化
中文白話解釋

透過圖形化元件將資料進行映射，藉此呈現數據資訊的技術

DM02 (CH2) 問答

01

Why Data Visualization?

為什麼需要資料視覺化
  • Gain insightinto an information space by mapping data onto graphical primitives透過將資料映射到圖形基元（點、線、形狀、顏色）上，深入了解資訊空間
  • Provide qualitative overviewof large data sets為龐大的資料集提供整體且直觀的質性敘述
  • Searchfor patterns, trends, structure, irregularities, relationships among data助於搜尋資料之間的模式（Patterns）、趨勢（Trends）、結構（Structure）、不規則性（Irregularities）之間的關聯性
  • Help find interesting regions and suitable parametersfor further quantitative analysis協助找出感興趣的資料區域與合適的參數，進行進一步的定量分析
  • Provide a visual proofof computer representations derived為電腦運算推導出的數據表示結果提供直觀的視覺化證明
02

Attribute Types

屬性類型
  • Nominal類別、狀態或事物名稱
    • 例：髮色、婚姻狀況、職業、身分證字號
  • Binary (0 or 1)名義屬性，僅有兩個狀態
    • Symmetric 對稱兩種結果同等重要。例：性別
    • Asymmetric 非對稱結果重要性不一樣，通常將 1 視為最重要或主要的結果。例：醫療檢測結果
  • Ordinal數值具有具意義的順序，但相鄰數值之間的差距大小是未知的。例：尺碼
  • Numeric 整數或實數
    • Interval等距，沒有絕對零點。例：攝氏、華氏溫度、日曆日期
    • Ratio有絕對零點，非負值。例：長度、貨幣金額

沒有符合的名詞，請試試其他關鍵字。
